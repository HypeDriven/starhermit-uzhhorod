# Uzhhorod

Publish the current StarHermit Engine 1.38.0 game to Starhermit production as **Uzhhorod**, with original cover art, a distinct favicon and a complete catalog description. Keep the existing gameplay and local-save compatibility.

The editable package is `game/`; `dist/` contains the production web upload. Declare artwork and description in `game/starhermit.txt` and include them in the generated integrity index.
